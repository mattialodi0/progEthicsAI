# A framework to measure fairness for text-to-image generative models

Features we can measure automatically:
- race: DeepFace
- gender: DeepFace
- demographic: DeepFace 
- emotion: DeepFace
- caption: Florence-2
- items: Florence-2
- feature vector: CLIP

Biases we are interested in reporting:
- race
- gender
- demographic
- culture
- socioeconomic
- actractiveness
- emotion

Other statistics:
- diversity (both intra-group and coverage)
- consistency
- wording influence
